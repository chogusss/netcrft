# NetCraft

Modern Neo-Brutalism landing page featuring 3D floating shapes, interactive tilt cards, and parallax scroll animations.

## Features
- **Neo-Brutalism Design**: High-contrast borders, bold geometry, vibrant palette, and typography powered by Space Grotesk & Inter.
- **Interactive 3D Elements**: Floating geometric shapes, mouse-reactive 3D tilt effects, and smooth scroll parallax.
- **Responsive**: Fully optimized for mobile, tablet, and desktop layouts.

## Getting Started
Open [landing.html](landing.html) directly in any modern web browser.
