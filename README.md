# NetCraft

Modern Neo-Brutalism landing page featuring 3D floating shapes, interactive tilt cards, and parallax scroll animations.

## Features
- **Neo-Brutalism Design**: High-contrast borders, bold geometry, vibrant palette, and typography powered by Space Grotesk & Inter.
- **Interactive 3D Elements**: Floating geometric shapes, mouse-reactive 3D tilt effects, and smooth scroll parallax.
- **Responsive**: Fully optimized for mobile, tablet, and desktop layouts.
- **Lead Generation**: WhatsApp contact flow, project estimator, and mobile quick actions.
- **Trust & Content**: Transparent concept-project labels, delivery assurances, detailed portfolio modal, and FAQ.
- **SEO & Accessibility**: Structured data, social metadata, sitemap, manifest, skip link, keyboard-friendly modal, and reduced-motion support.
- **Optimized Media**: Compressed JPEG portfolio assets with explicit dimensions and lazy decoding.

## Asset structure

All raster and vector image assets live in `assets/images/`. Optimized JPEG files
are used by the page, while the original PNG files are retained as source assets.

## Getting Started
Open [index.html](index.html) directly in any modern web browser.

## Production contact configuration

Before publishing, update `SITE_CONFIG` near the start of the inline script in
`index.html` with the production WhatsApp number and email address. The same
contact details are also present in the structured data and visible contact
section.
